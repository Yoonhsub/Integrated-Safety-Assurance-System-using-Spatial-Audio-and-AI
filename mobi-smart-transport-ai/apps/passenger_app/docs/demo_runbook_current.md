# 현재 검증 버전 시연 실행서

최신 main을 반영하지 않은 ajh_test 작업본 기준이다. 원본 영상·촬영 시각 미상인 앱 화면 녹화에서 재추론한 왼쪽 나무 한 프레임을 사용한다. 영상 전체 자동 재생은 아니다.

## 준비·진입

- APK: MOBI-demo-ready-debug.apk, 패키지 com.example.mobi_passenger_app.handoff. 기존 원본 앱과 별도이며 과거 검증 APK는 보존한다.
- Android에서 이어폰을 미디어 출력으로 연결하고 낮은 음량으로 준비한다. A를 문 역할 표식에 고정한다. A 식별자는 C3:00:00:5C:B9:47, 다른 B는 첫 리허설에서 OFF로 둔다. 거리·문 방향·문 열림·발밑 안전을 RSSI로 판단하지 않는다.
- 앱 → 이어폰·BLE 기기 점검 → 아래 탑승문 접근·중단 시연(실측 BLE).
- 이전에 도착 확인을 눌렀다면 반드시 뒤로 나갔다가 시연 화면에 다시 들어온다. arrived는 끝난 세션이며 STOP·안내 시작으로 재사용하지 않는다.
- 카메라 OFF. 각 장면에서 입력 출처를 말하고 화면 표시도 확인한다. 안내를 위한 실제 보행은 통제된 장소에서만 진행한다.

## 기록 탐지 경고 장면

1. 일반 ‘새 장애물 전체 스냅샷 모의 재생’은 OFF로 둔다.
2. 실측 BLE 스캔 시작(5분) → 안내 시작. 위험 정보가 없으면 재확인 안내가 나오는 것이 정상이다.
3. ‘AI 탐지 JSON 한 프레임 재생’을 펼쳐 **기록 영상 15초 · 왼쪽 나무 불러오기**를 누른다. 아직 소리는 나지 않는다.
4. **탐지 스냅샷 1회 재생**을 누른다. 처음 짧은 주의음이 왼쪽에서 들리는지 확인한다. 실제 머리 회전은 사용하지 않는다.
5. 2초 뒤 프레임이 만료되면 재확인 상태로 돌아간다. 한 번의 과거 프레임을 계속 최신 정보로 취급하지 않는다. 반복 청취는 1회 재생 버튼을 다시 누른다.

## 약 4분 리허설 순서

| 장면 | 조작 | 입력 표시 | 확인할 동작 |
|---|---|---|---|
| 정류장 장애물 | 위 기록 나무 프레임을 1회 재생 | AI 탐지: 기록 재생 / 위험: 모의 caution / 이어폰: 실측 | 왼쪽 주의음. 카메라 실측이라고 설명하지 않음 |
| 문 근처 안내 | 위험 none 선택 → 일반 모의 스냅샷 ON | BLE: 실측 / 장애물 없음: 모의 | 최신 A가 있을 때 근접 또는 접근 안내. 실제 구간이 화면에 뜬 대로 설명 |
| 위험 선점 | 안내가 시작되면 danger 선택 | 위험·방향: 모의 | 탑승 안내가 멈추고 경고 우선. none 복구 후 최신 A 확인 때만 재개 |
| 신호 상실·복구 | none 유지하며 A OFF, B로 대체하지 않음 → A ON | 목표 신호: 실측 / 장애물 없음: 모의 | 약 3초 관측 만료 뒤 위치 재확인, 새 A로 복구. 물리 차단·음향 지연은 별도 미측정 |
| 최종 도착 | 화면 near에서 문·발밑 안내 후 시연자 도착 확인 | 도착: 수동 | arrived·출력 종료. 완료 음성 없이 무음이 현재 동작 |

스캔은 5분 제한이므로 설정은 시작 전에 마치고 중간 문장 받아 적기 없이 진행한다. 한 프레임 재생 종료는 ‘장애물 제거를 실제 감지했다’는 뜻이 아니다. none은 모의 해제이다.

## 중단·복구

- STOP은 즉시 안내 종료. 앱을 홈으로 보내도 안내·스캔이 중지된다.
- 이어폰 연결 상실 후에는 새 경고도 차단하며 재연결만으로 자동 재생하지 않는다. 미디어 출력 연결을 확인하고 스캔·입력 설정 후 명시적으로 안내 시작한다.
- Bluetooth OFF, 권한 부족, 화면 이탈, 스캔 만료면 안내 상태를 확인하고 필요한 권한·연결을 복구한다. 종료된 세션은 화면 재진입 후 다시 준비한다.
- 상태나 입력이 불명확하면 전진 안내를 재개하지 말고 STOP을 누른다. 단일 비콘으로 실제 탑승 안전을 판정하지 않는다.

## 검증 범위

기존 APK에서 기록 탐지→왼쪽 cue→실제 왼쪽 청취, 모의 위험 선점, 목표 신호 상실·복구, 이어폰 상실 차단을 확인했다. 이번 준비 변경은 기록 JSON 불러오기 버튼·asset 추가이며 새 APK의 물리 청취·연속 리허설 결과는 아직 없다. 넓은 공간의 approaching→near 전환과 실제 카메라 현장 탐지는 미실행이다. 서버 판정·머리 회전·문 열림·단차/틈·자동 탑승 완료는 이번 시연의 검증 결과에 포함하지 않는다.
