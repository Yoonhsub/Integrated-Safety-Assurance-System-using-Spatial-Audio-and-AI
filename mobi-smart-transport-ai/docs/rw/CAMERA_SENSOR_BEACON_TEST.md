# 카메라·머리 WT901·비콘 통합 방향 시험

## 범위

머리에는 WT901, 휴대폰 후면 카메라는 손에 드는 배치용 로컬 진단이다. 휴대폰 rotation-vector로 후면 카메라 광축의 수평 방향을 추가 측정한다. 비콘은 선택한 A/B의 실측 평활 RSSI로 반복 간격만 정한다. 카메라의 단일 bus 내부 단일 bus_door를 수동으로 목표 비콘에 연결한다. 차량 인증·위험 판정·실제 탑승 안내가 아니다. 이전의 RSSI 기반 좌→정면→우 가정은 이 화면에서 사용하지 않는다.

계산은 `촬영 시점 카메라 수평 방향 변화 + bbox 광선 각도 - 현재 머리 회전 변화`다. 머리와 카메라를 같은 표식에 맞춰 각자 초기 영점을 잡는다. 카메라 광선은 pinhole 근사 atan((2*cx-1)*tan(FOV/2))를 사용한다. 휴대폰 방향은 촬영 시각에 250ms 이내인 샘플만 사용한다. 축과 WT901 회전 부호는 실제 장착 후 확인해야 한다. 화각 기본 60°는 가정값이며 실제 렌즈 화각 보정·각도 정확도 검증은 별도다. 수평을 유지하고 촬영한다. 자기장·회전 센서 드리프트 영향으로 실험 중 기준을 재확인한다.

## 실행

1. 기기 점검 → **카메라·센서·비콘 통합 방향 시험**.
2. 이어폰 연결. 비콘 A를 문 역할 표식에 고정하고 B는 끈다. 권한 허용 → 버스 탐색 시작(5분). 목표 A 선택.
3. 아래 카메라 영역에서 카메라 시작과 권한 허용을 먼저 완료한다. 카메라 권한 창이 뜨면 앱 비활성화 처리가 일어나므로 기준 설정은 그 후 진행한다.
4. WT901 센서 연결 → 머리를 정면으로 두고 도로 정면을 기준으로 설정.
5. 휴대폰 방향 시작. 휴대폰을 세우고 후면 카메라가 같은 정면 표식을 보게 한다. 휴대폰 방향 수신 중인지 확인한다.
6. 현재 촬영 영상 기준 수평 화각 입력. 기본값으로 시험하면 근사 방향 시험으로만 기록한다.
7. 화면의 단일 문을 선택 비콘 시험 대상으로 수동 연결 체크. 여러 버스·문이 있으면 시험하지 않는다.
8. 머리·카메라 동일 정면 설정. 촬영 시점의 최신 자세와 단일 문이 잡히면 버스 소리 시작 활성화. 필요시 센서 회전 부호 반대로 설정 후 기준 재설정.
9. 새 입력으로 수신이 복구돼도 소리는 수동 시작한다. 중단 원인 문구 확인.

## 단일 출력·중단 조건

카메라 검출 한 프레임당 단일 문만 사용한다(bus confidence >=.5, door >=.55, 문 면적 70% 이상이 bus 박스 안). 여러 bus/door·미검출이면 이전 방향을 즉시 지운다. 후면 카메라 전용. 카메라 관찰 1초, 휴대폰 방향 300ms, 머리 센서 1초, 목표 비콘 3초 이내의 최신 값이 모두 있어야 한다. 센서 재보정·연결 상실·화면 이탈 시 기준을 무효화한다. 네이티브 이어폰 출력 제한·watchdog·5분 종료는 기존 경로를 재사용한다. 후방 목표는 기존 수정에 따라 방향 없는 중앙 근접음이다. 실제 장애물 경고 우선순위 시연은 이번 문 추적 시험에 포함하지 않는다.
