# 개발자 B 진행 현황 및 팀 공유 자료

## 한 문장 요약

개발자 B는 카메라 화면에서 버스를 인식하고, 버스의 화면상 위치·거리·접근 여부를
판단해 음성 안내 담당 모듈에 넘기는 AI 비전 기능을 맡았다. 현재 일반 버스를 찾는
Android용 TFLite 모델은 준비·검증됐고, 버스 문까지 인식하는 첫 커스텀 모델은 공개
데이터로 학습 중이다.

## 완료한 작업

| 구분 | 완료 내용 | 의미 |
| --- | --- | --- |
| Android AI 기준선 | COCO 버스 모델을 Android용 `.tflite`로 변환 | 서버 없이 휴대폰 안에서 버스 탐지 가능 |
| 모델 입출력 규칙 | `640×640 RGB float32` 입력, `[1,84,8400]` 출력 해석 확정 | 앱 담당자가 같은 규칙으로 구현 가능 |
| 버스 위치 판단 | `LEFT / CENTER / RIGHT` | 어느 방향에 버스가 있는지 전달 |
| 상대 거리 판단 | `FAR / MEDIUM / NEAR` | 화면 속 버스 크기를 기준으로 가까움 판단 |
| 움직임 판단 | `APPROACHING / STABLE / RECEDING` | 이전 프레임과 비교해 가까워지는 흐름 판단 |
| 실제 모델 검증 | 공개 버스 이미지·영상으로 TFLite 실행 | 영상에서 `CENTER/MEDIUM` → `LEFT/NEAR/APPROACHING` 전환 확인 |
| 앱 담당자 인계 | Android TFLite 인계서 작성 | 카메라·권한·모델 실행을 앱 담당자가 구현 가능 |
| 데이터셋 준비 | 라벨링 기준, 개인정보 처리, 자동 검증기 작성 | 잘못된 라벨·파일 누락을 학습 전에 검사 |
| 버스 문 데이터 확보 | 공개 데이터 1,884장 변환 | `bus`, `bus_door` 모델 학습 시작 |

## 공개 버스 문 데이터셋 처리 결과

| 항목 | 결과 |
| --- | ---: |
| 전체 이미지 | 1,884장 |
| 학습 / 검증 / 테스트 | 1,507 / 188 / 189장 |
| 유지한 `bus`·`bus_door` 라벨 | 4,459개 |
| 제거한 `Number` 라벨 | 576개 |
| 데이터셋 형식 검사 | 오류 0개 |

원본의 `Front_door`, `Rear_door`는 프로젝트의 단일 `bus_door` 클래스로 합쳤고,
`Number`는 안내 기능과 무관하므로 제외했다.

## 현재 진행 중인 작업

공개 데이터로 `bus`, `bus_door` 두 클래스를 인식하는 YOLO11n 모델을 CPU에서 20회
학습 중이다. GPU가 없는 환경이라 시간이 걸리며, 완료 전에는 버스 문 탐지 정확도를
확정하지 않는다. 학습이 끝나면 검증·테스트 성능을 확인하고, 통과한 가중치만
Android용 TFLite로 변환한다.

## 개발 일정에서 남은 개발자 B 작업

1. `bus_door` 모델 학습 완료, 정확도·오탐 검증, TFLite 변환
2. 전방 장애물(`obstacle`) 데이터 수집·라벨링·학습
3. `bus_stop`, 점자블록, 차도·보도 등 7개 프로젝트 클래스 확장
4. Context·Audio 모듈과 실제 안내 이벤트 통합 검증
5. Android 실기기에서 카메라 입력과 모델 결과 비교
6. 실제 정류장에서 낮·밤·거리·흔들림 조건으로 신뢰도 임계값과 프레임 간격 조정

## 다른 개발자에게 전달할 내용

> 개발자 B는 버스 인식 AI 기준선을 담당했습니다. 현재 Android용 TFLite 모델은 일반
> 버스를 탐지할 수 있고, 카메라 프레임에서 버스의 방향, 화면상 거리, 접근 여부를
> `LEFT`, `NEAR`, `APPROACHING` 같은 안내 후보로 반환할 수 있습니다.
>
> 앱 담당자는 `ANDROID_TFLITE_HANDOFF.md`에 따라 카메라 프레임을 640×640 RGB
> float32 형식으로 바꿔 TFLite 모델에 넣고, 결과를 화면 또는 안내 흐름에 연결하면
> 됩니다.
>
> Context·Audio 담당자는 AI가 보내는 방향·거리·접근 상태를 받아 실제 음성 문구,
> 공간음향, 중복 안내 방지 규칙을 적용하면 됩니다.
>
> 현재 공개 데이터 1,884장으로 버스와 버스 문을 함께 찾는 첫 커스텀 모델을 학습
> 중입니다. 장애물·점자블록 등 나머지 안전 기능은 국내 보행 환경 데이터를 추가
> 확보한 뒤 확장해야 합니다.
