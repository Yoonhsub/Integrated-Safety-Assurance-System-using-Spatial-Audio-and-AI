# 버스 문 모델 학습 산출물

## 목적

버스와 버스 문을 구분하는 YOLO11n 학습 결과를 보관한다. Android 실기기 검증은 개발
일정의 앱 연동 단계에서 진행하며, 이 문서는 그 전 단계의 학습 완료 기록이다.

## 학습 결과

| 항목 | 값 |
| --- | --- |
| 데이터 | 공개 버스 문 이미지 1,884장 |
| 클래스 | `bus`, `bus_door` |
| 학습 횟수 | 20 epochs |
| 전체 mAP50 | 0.993 |
| 전체 mAP50-95 | 0.890 |
| `bus` mAP50 / mAP50-95 | 0.995 / 0.965 |
| `bus_door` mAP50 / mAP50-95 | 0.993 / 0.815 |
